# Power BI dashboard: step-by-step build guide

Everything the dashboard needs is generated by `python -m src.pipeline` into `powerbi/data/`.
You need **Power BI Desktop** (free, Microsoft Store) on Windows.

| File | Grain | Role |
|---|---|---|
| `Titles.csv` | 1 row per title | **Fact / hub table** (type, dates, rating, runtime, cluster, t-SNE coords…) |
| `Title_Genres.csv` | title × genre | bridge |
| `Title_Countries.csv` | title × country | bridge |
| `Title_Cast.csv` | title × actor | bridge |
| `Title_Directors.csv` | title × director | bridge |
| `Clusters.csv` | 1 row per K-Means cluster | ML output |
| `Model_Evaluation.csv` | 1 row per method | ML evaluation |
| `Classifier_Metrics.csv` | 1 row per task/metric | supervised NLP results vs baselines |
| `Genre_Classifier.csv` | 1 row per genre | per-genre precision / recall / F1 |

---

## Step 1: Load the data
1. **Home → Get data → Text/CSV** → load every CSV in `powerbi/data/` (choose *Load*).
2. **Transform data** (Power Query) → `Titles` table → set data types:
   `date_added` = **Date**, `release_year`, `year_added`, `month_added`, `cluster` = **Whole number**,
   `duration_min`, `seasons`, `tsne_x`, `tsne_y` = **Decimal number**. Close & Apply.

## Step 2: Apply the theme
**View → Themes → Browse for themes** → `powerbi/Netflix_Theme.json` (dark Netflix style).

## Step 3: Build the model (star schema)
1. Create the **Date** table using the DAX in `DAX_Measures.md` §1 and mark it as a date table.
2. In **Model view**, create the relationships:

| From (one side) | To (many side) | Cross-filter |
|---|---|---|
| `Date[Date]` | `Titles[date_added]` | Single |
| `Titles[show_id]` | `Title_Genres[show_id]` | **Both** |
| `Titles[show_id]` | `Title_Countries[show_id]` | **Both** |
| `Titles[show_id]` | `Title_Cast[show_id]` | **Both** |
| `Titles[show_id]` | `Title_Directors[show_id]` | **Both** |
| `Clusters[cluster]` | `Titles[cluster]` | Single |

*"Both" lets a genre/country slicer filter the titles (many-to-many through the bridge).*

3. Add all measures from `DAX_Measures.md` §2 to §5.

```
          Date ──1:*──► TITLES ◄──*:1── Clusters
                     ▲  ▲   ▲   ▲
       Title_Genres ─┘  │   │   └─ Title_Directors
        Title_Countries ┘   └─ Title_Cast
```

## Step 4: Build the report pages (canvas 1280 × 720)

### Page 1: Executive Overview
- **Header**: text box "NETFLIX CONTENT DASHBOARD" (red #E50914) + card with `[Dashboard Subtitle]`.
- **Slicers row** (top): `Titles[type]` (tile style), `Date[Year]` (between slider),
  `Titles[maturity_group]` (dropdown), `Title_Genres[genre]` (dropdown, search on).
- **KPI cards**: `[Total Titles]`, `[Movies]`, `[TV Shows]`, `[Countries]`, `[Avg Movie Duration (min)]`, `[Titles Added YoY %]`.
- **Line chart**: X = `Date[Year]`, Y = `[Total Titles]`, Legend = `Titles[type]` → *Content added per year*.
- **Filled map**: Location = `Title_Countries[country]`, Color saturation = `[Total Titles]` → *Where content comes from*.
- **100% stacked bar**: Y = `Titles[maturity_group]`, X = `[Total Titles]`, Legend = `Titles[type]`.

### Page 2: Content Deep-Dive
- **Clustered bar**: `Title_Genres[genre]` vs `[Total Titles]` (Top N filter = 15).
- **Column chart**: `Titles[rating]` vs `[Total Titles]`, Legend = `type`.
- **Column chart**: `Titles[Duration Bucket]` vs `[Movies]` (*Movie runtime*).
- **Matrix heatmap**: Rows = `Date[Year]`, Columns = `Date[Month]`, Values = `[Total Titles]`,
  then *Cell elements → Background color → gradient* (dark → red) → *When are titles added?*
- **Stacked column**: `Titles[decade]` vs `[Total Titles]`, Legend = `type`.
- **Card**: `[Median Years to Netflix]`, `[Recent Content %]`.

### Page 3: People & Geography
- **Bar**: `Title_Directors[director]` (Top N 10 by `[Total Titles]`).
- **Bar**: `Title_Cast[actor]` (Top N 10).
- **Treemap**: Category = `Title_Countries[country]`, Values = `[Total Titles]` (Top N 20).
- **Decomposition tree**: Analyze = `[Total Titles]`, Explain by = `type`, `country`, `genre`, `rating`.
- **Table**: `title`, `type`, `release_year`, `rating`, `primary_genre` with a search slicer on `title`.

### Page 4: ML Model Insights
- **Scatter chart**: X = `Titles[tsne_x]` (*Don't summarize*), Y = `Titles[tsne_y]`,
  Legend = `Titles[cluster_name]`, Tooltips = `title` → **content map of the 12 K-Means clusters**.
- **Bar**: `Clusters[cluster_name]` vs `Clusters[size]`.
- **Table**: `Clusters[cluster_name]`, `top_genres`, `top_terms`, `pct_movies`.
- **Clustered bar**: `Model_Evaluation[Method]` vs `Genre Precision@10`, `People Hit@10`,
  `Plot Similarity@10` → *Hybrid model vs baselines*.
- **Cards**: `[Hybrid Genre Precision]`, `[Hybrid People Hit]`.
- **Clustered bar**: `Classifier_Metrics[Task]` vs `Model` and `Baseline` → *supervised models vs baselines*.
- **Bar**: `Genre_Classifier[Genre]` vs `F1` (sorted) → *which genres are predictable from the synopsis*.

### Finishing touches
- **Format → Edit interactions** so slicers filter all visuals.
- Add page navigation buttons (Insert → Buttons → Navigator → Page navigator).
- Add tooltips pages or drill-through on `Titles[title]` for a title detail page (optional).
- Save as `powerbi/Netflix_Dashboard.pbix`.

## Step 5: Publish & embed in the live website
1. **Home → Publish** → sign in with your (college/work) Microsoft account → choose *My workspace*.
2. Open the report on app.powerbi.com → **File → Embed report → Publish to web (public)** → copy the
   *embed URL* (`https://app.powerbi.com/view?r=...`).
   *Publish to web must be enabled by your tenant admin; if it's blocked, take screenshots or
   export to PDF (File → Export → PDF) for your report instead.*
3. In Streamlit Cloud → your app → **Settings → Secrets** add:
   ```toml
   POWERBI_EMBED_URL = "https://app.powerbi.com/view?r=YOUR_LINK"
   ```
   The dashboard then appears at the bottom of the **Analytics Dashboard** page of the website.
